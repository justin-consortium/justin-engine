# JustIn Events

The **JustIn events** package (@just-in/events) is the foundation of the [JustIn Framework](https://miacollaborative.github.io/justin-framework).

Docs for installing and using **JustIn Events** and, eventually, other aspects of the Framework, can be found at the [JustIn Events site](https://miacollaborative.github.io/justin-core).

The fastest and best way to get started with JustIn is to try out one of our [examples](https://github.com/MIACollaborative/justin-examples).
